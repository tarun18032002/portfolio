I’m Tarunkumar, an AI Engineer in Bangalore. I work where language models stop being demos and start being systems: multi-agent orchestration, tool calling against real enterprise APIs, retrieval that has to return the right document, and guardrails that stop an agent doing the wrong thing to someone’s order.
